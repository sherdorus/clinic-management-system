What's inside

Four parts, each doing one job

REST API

CRUD endpoints for patients, doctors, appointments, visits and medical records.

Infrastructure

Docker Compose, Nginx as reverse proxy, HTTPS via Let's Encrypt, MySQL and Redis. Health and management endpoints stay internal — not exposed publicly.

Observability

Actuator metrics through Prometheus and Grafana, logs centralized in Loki via Promtail.

Delivery

Automated build and deployment using GitHub Actions — no manual steps.

Deployment

Run the way a real service is run

Metrics and logs are collected centrally instead of being read off the box by hand.
